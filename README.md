## Repository Overview
This repository serves as a centralized hub for all simulation files, theoretical design calculations, circuit schematics, and final lab reports for the **ECE311: Electronic Circuits 2** course. 

The primary objectives of these laboratory assignments are to:
- Design, analyze, and optimize BJT and MOSFET amplifier stages.
- Determine DC operating points ($Q$-points) and verify maximum unclipped peak-to-peak AC voltage swings.
- Bridge theoretical circuit design with practical simulation using **NI Multisim**.
- Compile rigorous technical reports formatted in **LaTeX**.
